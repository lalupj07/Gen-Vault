|-------|--------|

| Subcategory | Backup + manage |

Keep **Security** as the extra category if only one secondary is allowed.

---

## Privacy policy

| Field | Value |
|-------|--------|
| Does this product access, collect, or transmit personal information? | **Yes, my product uses personal information** |
| Privacy policy URL | `https://www.genxisinnovation.in` |

### Why “Yes”
GenVault stores usernames, passwords, notes, and attachments on device. Optional HIBP breach checks send a password hash prefix over the network.

### Privacy page must cover
- Vault data is encrypted and stored only on the user’s device
- No GenXis cloud account or telemetry
- Optional HIBP: only a SHA-1 hash prefix when the user runs a breach check
- Contact: genxisinnovation@outlook.com

Publish a real privacy policy page at that URL before submitting (not only a homepage).
